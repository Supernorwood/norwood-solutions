# Norwood Solutions static site

Upload all files and the `assets` directory to the root of a GitHub repository. Enable GitHub Pages from the main branch/root. Set the custom domain to `norwood-solutions.com` in Pages settings; keep the CNAME file. Point the domain DNS to GitHub Pages after the site is live, then verify all pages and email before canceling Vultr. The site uses no server code; contact links open email and phone.

The navigation uses root paths (`/about`, `/rcc`, `/contact`) and is intended for the custom domain. A project repository preview under `username.github.io/repository` will need a base-path adaptation; the custom domain serves at the root.
